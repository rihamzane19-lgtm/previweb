## Description du projet

PréviWeb est une interface web destinée à l'importation, à l'analyse et à la prévision de séries chronologiques à partir de fichiers CSV.

L'application est organisée en trois sections principales :

- **Importer :** permettre à l'utilisateur d'importer un fichier CSV au format `date,valeur`.
- **Analyser :** préparer l'affichage du graphique de la série chronologique et du tableau des observations.
- **Prévoir :** préparer l'affichage des résultats de prévision.
